# Брокеры сообщений — интерактивный тренажёр

Kafka, RabbitMQ, очереди, топики, партиции, гарантии доставки, паттерны — **руками**, а не по слайдам.
Откройте `index.html` в браузере: работает офлайн, ничего устанавливать не нужно, прогресс сохраняется в браузере.

## 19 разделов — единое повествование

Идите по порядку: кнопка «Дальше →» внизу каждой вкладки ведёт к следующей. Термины объясняются **до** того, как встретятся в примерах; подчёркнутые слова дают определение при наведении.
